# 🎯 ربات مسابقه‌ی پیش‌بینی نرخ روز — تلگرام + بله (Cloudflare Workers رایگان + Turso)

`@nerkhemroozchand_predict_bot`

کاربران هر روز قیمت **دلار، طلا ۱۸، سکه و اونس** را حدس می‌زنند، XP می‌گیرند، در لیدربورد رقابت می‌کنند،
با ورود به ۱۰٪ برتر «👑 لجندری» می‌شوند و «سیگنال اجماع» را می‌بینند. کارت تصویری هر حدس (با لینک رفرال) قابل فوروارد است،
و نتایج روزانه خودکار در کانال شما منتشر می‌شود (چسبندگی کانال + رشد).

---
## ۱) ساختار پروژه
```
src/index.js      ورودی Worker: وب‌هوک‌ها، مسیرهای ادمین، Cron هر دقیقه
src/config.js     ⭐ نمادها، کوئری منبع قیمت، ساعت‌ها، امتیازدهی، لجندری  (بیشترین تغییرات شما اینجاست)
src/bot.js        منطق ربات (مشترک تلگرام و بله)
src/market.js     تشخیص تعطیلی، ثبت قیمت مرجع، امتیازدهی، لجندری شبانه
src/outbox.js     صف پیام‌ها + تولید کارت‌ها
src/card.js       طراحی کارت تیره (Dark) + رندر با Browser Rendering + کارت متنی جایگزین
src/db.js         کلاینت Turso (HTTP) + شمای جدول‌ها
src/platform.js   API یکسان تلگرام/بله
test/sim.mjs      شبیه‌سازی کامل (npm test)
schema.sql        شمای جدول‌ها (برای مرجع)
```

## ۲) پیش‌نیازها
1. Node.js نسخه ۲۰ یا بالاتر
2. حساب Cloudflare (پلن رایگان)
3. دیتابیس Turso (همان دیتابیس فعلی شاخص‌ها): **URL** و **Auth Token**
   - `turso db show <نام-دیتابیس> --url`  و  `turso db tokens create <نام-دیتابیس>`
   - یا از داشبورد Turso ← دیتابیس ← Generate Token
4. ساخت ربات:
   - **تلگرام:** از `@BotFather` دستور `/newbot` ← توکن
   - **بله:** از `@botfather` در خود بله (بات فادر) ← ساخت ربات ← توکن
5. ربات را در هر دو پیام‌رسان **ادمین کانال** کنید (برای بررسی عضویت و ارسال نتایج).

## ۳) متغیرها
### محرمانه (با `wrangler secret put NAME` ست می‌شوند)
| نام | توضیح |
|---|---|
| `TURSO_URL` | مثل `libsql://db-org.turso.io` |
| `TURSO_AUTH_TOKEN` | توکن Turso |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام |
| `BALE_BOT_TOKEN` | توکن ربات بله (اگر بله نمی‌خواهید خالی بگذارید) |
| `WEBHOOK_SECRET` | یک رشته‌ی تصادفی طولانی، فقط `A-Z a-z 0-9 _ -` |
| `ADMIN_KEY` | رمز قوی برای مسیرهای `/admin/*` |

### غیرمحرمانه (داخل `wrangler.toml` ← بخش `[vars]`)
| نام | توضیح |
|---|---|
| `TELEGRAM_BOT_USERNAME` | بدون @ ، مثل `nerkhemroozchand_predict_bot` |
| `BALE_BOT_USERNAME` | آیدی ربات در بله (بدون @). خالی = لینک‌های بله غیرفعال |
| `CHANNEL_TELEGRAM` / `CHANNEL_BALE` | مثل `@nerkhemroozchand` — برای عضویت اجباری و انتشار نتایج. خالی = غیرفعال |
| `REQUIRE_CHANNEL_JOIN` | `"true"` یا `"false"` |
| `ADMIN_IDS` | ادمین‌های ربات: `telegram:123456,bale:987654` |
| `PREMIUM_CONTACT` | آیدی پشتیبانی برای خرید پریمیوم، مثل `@support` |

## ۴) راه‌اندازی قدم‌به‌قدم
```bash
npm install
npx wrangler login
npx wrangler deploy                      # اولین دیپلوی (آدرس workers.dev را یادداشت کنید)

npx wrangler secret put TURSO_URL
npx wrangler secret put TURSO_AUTH_TOKEN
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put BALE_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put ADMIN_KEY
```
سپس (به‌جای `YOUR` آدرس Worker و `KEY` همان ADMIN_KEY):

1. **ساخت جدول‌ها:** `https://YOUR.workers.dev/admin/init?key=KEY`
2. **دیدن جدول‌های فعلی Turso:** `.../admin/tables?key=KEY`
   ← ساختار جدول قیمت‌ها را ببینید و کوئری‌های `source` را در `src/config.js` مطابق آن اصلاح کنید (مهم‌ترین قدم!) ← دوباره `npx wrangler deploy`
3. **تست خواندن قیمت‌ها:** `.../admin/prices?key=KEY` — باید برای هر ۴ نماد `price` و `ts` برگردد.
4. **ست‌کردن وب‌هوک و دستورهای ربات (تلگرام + بله):** `.../admin/setup?key=KEY`
5. در تلگرام/بله به ربات `/start` بزنید. برای ادمین‌شدن، شناسه‌ی عددی خود را در `ADMIN_IDS` بگذارید.
6. تست دستی چرخه‌ی زمان‌بندی: `.../admin/tick?key=KEY` (Cron هر دقیقه خودش اجرا می‌شود).

> اگر جدول قیمت شما فقط یک ردیف بدون تاریخ بروزرسانی دارد، ستون `ts` را حذف کنید؛ ولی در این حالت محافظت «منبع قیمت کهنه» غیرفعال می‌شود.

## ۵) رفتار سیستم (تغییرات و تکمیل‌های من نسبت به طراحی اولیه)
- **پنجره‌های زمانی:** دقیقاً طبق طراحی شما (داخلی: تا ۱۲:۰۰ / قیمت مرجع ۱۷:۰۰ — اونس: تا ۱۴:۰۰ / ۲۳:۳۰ و شنبه‌ویکشنبه تعطیل). همه در `config.js`.
- **تشخیص تعطیلی مقاوم‌تر:** هر ۱۰ دقیقه در بازه‌ی بررسی، قیمت ذخیره می‌شود (Snapshot). بازار «تعطیل» است اگر هم نوسان همان بازه **و** هم اختلاف با قیمت نهایی روز کاری قبل ≤ آستانه باشد. اگر داده‌ی منبع کهنه باشد تصمیمی گرفته نمی‌شود (تا با خرابی منبع، روز اشتباهی باطل نشود).
- **امتیازدهی ترکیبی (به‌جای صرفاً رتبه):** `XP = امتیاز دقت (۰..۱۰۰ بر پایه‌ی درصد خطا) + جایزه‌ی رتبه (۵۰/۳۰/۱۵ با حداقل ۳ شرکت‌کننده) + ۵ مشارکت`. به این ترتیب تک‌نفره بودن امتیاز کامل نمی‌دهد. کاملاً قابل تغییر در `SCORING`.
- **ضد خطا/تقلب:** حدس‌های بیش از ۱۰٪ دورتر از قیمت لحظه‌ای رد می‌شود؛ هر کاربر در هر نماد در روز یک حدس؛ نام مستعار یکتا؛ رفرال فقط وقتی حساب می‌شود که دعوت‌شده **اولین پیش‌بینی** را ثبت کند.
- **Alias:** ناشناس / @username / نام دلخواه؛ قابل تغییر از پروفایل. کاربر «ناشناس» در کارت آواتار نمی‌گیرد (حریم خصوصی).
- **لجندری:** هر شب ۰۰:۰۵ میانگین دقت ۳۰ روز اخیر (حداقل ۵ پیش‌بینی) محاسبه و ۱۰٪ برتر علامت 👑 می‌گیرند (حداقل ۵ کاربر واجد شرایط لازم است). سیگنال اجماع فقط وقتی حداقل ۳ لجندری حدس زده باشند نمایش داده می‌شود.
- **دسترسی به سیگنال:** لجندری، یا پریمیوم (`/premium <شناسه> <روز>` توسط ادمین)، یا ۵ دعوت موفق (دائمی).
- **لیدربورد:** ۵ جدول (کلی + هر نماد)؛ رتبه‌ی شخصی هم نمایش داده می‌شود. جدول `leaderboards` هر بار از روی `predictions` بازسازی می‌شود، پس هیچ‌وقت XP دوباره شمرده نمی‌شود.
- **کانال:** نتایج روزانه (۳ نفر برتر) و اعلام تعطیلی خودکار در کانال منتشر می‌شود. 
- **دستورهای ادمین:** `/stats` ، `/premium id days` ، `/broadcast متن`

## ۶) محدودیت‌های پلن رایگان (و راه‌حل‌هایی که اعمال شده)
| محدودیت | راه‌حل در پروژه |
|---|---|
| ۵۰ درخواست خروجی در هر اجرا | همه‌ی پیام‌های انبوه (نتایج، اعلان‌ها) به‌جای ارسال یکجا، در **صف (outbox)** می‌روند و هر دقیقه ~۱۸ پیام ارسال می‌شود. ۱۰۰۰ کاربر ⇒ حدود ۵۵ دقیقه. دستورهای دیتابیس هم دسته‌ای (Batch) ارسال می‌شوند. |
| Browser Rendering: ۱۰ دقیقه/روز و ۳ مرورگر جدید در دقیقه | کارت‌ها «ناهمزمان» و حداکثر ۲ کارت در دقیقه ساخته می‌شوند. اگر سهمیه تمام شد ربات خودکار **کارت متنی** (با همان دکمه‌ی رفرال) می‌فرستد. تخمین: چند صد کارت تصویری در روز. |
| ۱۰ms زمان CPU در هر درخواست | کد سبک نوشته شده؛ اگر در لاگ خطای `1102` دیدید (تعداد کاربران خیلی زیاد)، پلن ۵ دلاری Workers مشکل را حل می‌کند. |
| ۵ Cron Trigger | فقط ۱ Cron (هر دقیقه) استفاده شده. |

اگر نمی‌خواهید Browser Rendering استفاده شود: دو خط `[browser]` در `wrangler.toml` را کامنت کنید (کارت متنی ارسال می‌شود).

## ۷) نکات مهم بله
- API بله با تلگرام سازگار است (`tapi.bale.ai`). لینک دعوت: `https://ble.ir/<username>?start=ref_ID` — یک‌بار با یک حساب دیگر تست کنید.
- سرورهای بله داخل ایران هستند. اگر پیام‌های بله به Worker نرسید (آدرس `workers.dev` گاهی فیلتر/کند است): یک **دامنه‌ی اختصاصی** روی Cloudflare به Worker وصل کنید (Workers → Settings → Domains & Routes) و دوباره `/admin/setup` را با همان دامنه باز کنید.
- بررسی عضویت کانال بله نیاز دارد ربات ادمین کانال باشد؛ اگر بررسی ممکن نباشد، ربات اجازه‌ی شرکت می‌دهد (Fail-open).
- کاربر تلگرام و بله دو حساب جدا هستند (شناسه‌ی داخلی جدا) ولی لیدربورد مشترک است.

## ۸) عیب‌یابی
- `npx wrangler tail` لاگ زنده را نشان می‌دهد.
- `/admin/tick` گزارش هر بخش (`market / outbox / cards`) و تعداد درخواست‌های خروجی را برمی‌گرداند.
- ربات جواب نمی‌دهد ← `/admin/setup` را دوباره اجرا کنید و خروجی `setWebhook` را بخوانید.
- خطای «قیمت لحظه‌ای در دسترس نیست» ← `/admin/prices` و کوئری‌های `config.js`.
- کارت‌ها متنی می‌آیند ← سهمیه‌ی Browser Rendering تمام شده یا Binding فعال نیست (طبیعی و بی‌خطر).

## ۹) تست محلی
`npm install` سپس `npm test` (Node 22+): یک شبیه‌سازی کامل با SQLite محلی، شامل ثبت حدس، رفرال، امتیازدهی، اعلان‌ها، لجندری، تعطیلی و بله.

## ۱۰) پیشنهاد توسعه (بعد از راه‌اندازی)
لیدربورد هفتگی (ریست شنبه‌ها)، «استریک» روزهای متوالی، دکمه‌ی اشتراک‌گذاری کارت در استوری، پرداخت خودکار پریمیوم (زرین‌پال/…)، نمودار عملکرد شخصی.

⚠️ این مسابقه صرفاً سرگرمی است و توصیه‌ی مالی نیست.
